### **Meeting Minutes**

**Meeting Date**: February 25, 2025
 **Meeting Location**: MVB 2.11
 **Attendees**: All team members

------

### **Agenda**

1. **Think Aloud Testing**
   - **Study Planning (20 minutes)**
     - Assign a **Facilitator** and **two Observers**.
     - Select **two short tasks** for the participant to complete.
   - **Recruit a participant** (from a neighboring group).
   - **Conduct the test (10 minutes)**
     - Explain the tasks to the participant.
     - Remind the participant to **Think Aloud**.
     - Observers **record critical moments**.
   - **Data Integration (10 minutes)**
     - Observers compile and organize key findings.
   - **Follow-up Tasks**
     - The team will analyze the test data.
     - Findings will be documented and uploaded to the GitHub repository.
2. **Heuristic Evaluation**
   - Assign a **Facilitator** to ensure the game runs smoothly.
   - Invite an **external observer (Expert) for evaluation**.
   - Phase 1 (10 minutes): 
     - The observer **familiarizes themselves with the game** and explores the gameplay.
   - Phase 2 (10 minutes): 
     - The observer **records usability issues independently** using the provided form.
   - Optional Approaches: 
     - Conduct a second evaluation in parallel (requires an additional setup).
     - Or, conduct a **second evaluation after the first one**.
   - Follow-up Tasks: 
     - The team will analyze expert feedback and identify areas for improvement.
     - Findings will be documented and updated in the GitHub repository and report.
3. **Team Assignments**
   - Game Difficulty Adjustments
     - Implement **two difficulty levels** (e.g., adjust speed, increase level difficulty, strengthen enemies, remove power-ups, etc.).
     - Ensure players can **select between different difficulty levels**.
   - Write and Submit User Evaluation Report
     - Document findings from **Think Aloud and Heuristic Evaluation**, then upload them to the GitHub repository.
   - Plan Further Qualitative Evaluation
     - Recruit more testers outside the group for **deeper evaluation**.
